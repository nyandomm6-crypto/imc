┌─ ⭐ FONCTIONNALITÉS PRINCIPALES ────────────────────────────────────────────────┐
│                                                                                 │
│  1. SYSTÈME DE REMISE GOLD                                                    │
│     ├─ 14% de réduction automatique                                           │
│     ├─ Calcul: prix_gold = prix_normal * 0.86                                 │
│     └─ Activation via AbonnementModel::hasGoldSubscription()                   │
│                                                                                 │
│  2. ALGORITHME DE SUGGESTIONS INTELLIGENTES                                   │
│     ├─ Prise de masse: Régime+Sport → Régime → Sport                          │
│     ├─ Perte de poids: Sport → Régime+Sport → Régime                          │
│     └─ Maintien: Régime+Sport → Régime → Sport                                │
│                                                                                 │
│  3. AUTO-SUGGESTION RÉGIME/SPORT                                              │
│     ├─ Sélection automatique lors demande                                      │
│     ├─ Basée sur objectif actif utilisateur                                    │
│     └─ Sauvegarde regime_id + sport_id                                        │
│                                                                                 │
│  4. WORKFLOW COMPLET DES DEMANDES                                             │
│     ├─ User demande offre → statut='demande'                                   │
│     ├─ Admin accepte/rejette                                                   │
│     └─ Prix calculé + sauvegardé                                               │
│                                                                                 │
│  5. DASHBOARD STATISTIQUES                                                    │
│     ├─ Total utilisateurs                                                     │
│     ├─ Utilisateurs Gold (%)                                                   │
│     ├─ Total offres                                                            │
│     ├─ Demandes en attente/acceptées                                           │
│     └─ Revenu total généré                                                     │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌─ 🧪 EXEMPLE D'UTILISATION COMPLÈTE ────────────────────────────────────────────┐
│                                                                                 │
│  SCÉNARIO: Utilisateur Gold achète une offre                                  │
│                                                                                 │
│  1. User va à /offres                                                          │
│  2. Voit: "Offre Sport 49.99€ → 42.99€ (-14%)"                                │
│  3. Badge: "⭐ Abonnement Gold"                                                 │
│  4. Clique "Demander cette offre"                                              │
│  5. Sport cardio auto-sélectionné                                              │
│  6. Demande créée: statut='demande'                                            │
│                                                                                 │
│  7. Admin va à /admin/offres/demandes/all                                      │
│  8. Voit demande en attente                                                    │
│  9. Clique "Voir détails"                                                      │
│  10. Clique "✓ Accepter"                                                       │
│  11. Système détecte: User Gold                                                │
│  12. Calcule: 49.99€ * 0.86 = 42.99€                                          │
│  13. Sauvegarde: prix_paye=42.99€, statut='acceptée'                           │
│  14. Dashboard: +1 demande acceptée, +42.99€ revenu                            │
│                                                                                 │
